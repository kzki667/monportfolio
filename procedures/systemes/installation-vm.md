# Installation d’une machine virtuelle

## Objectif
Déployer une VM prête à être configurée pour un service ou un test.

## Étapes
1. Créer la VM dans l’hyperviseur.
2. Affecter CPU, RAM, stockage et réseau.
3. Monter l’ISO d’installation.
4. Installer le système d’exploitation.
5. Configurer le réseau et les mises à jour.
6. Créer un snapshot de base si nécessaire.
