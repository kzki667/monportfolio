# Création d’un utilisateur Active Directory

## Objectif
Créer un compte utilisateur conforme à l’organisation.

## Étapes
1. Ouvrir la console Active Directory Users and Computers.
2. Sélectionner l’unité d’organisation adaptée.
3. Créer le nouvel utilisateur.
4. Définir l’identifiant et le mot de passe initial.
5. Ajouter les groupes nécessaires.
6. Vérifier les droits et les partages associés.

## Vérifications
- Le compte apparaît dans la bonne OU
- Les groupes sont corrects
- L’utilisateur peut ouvrir sa session
